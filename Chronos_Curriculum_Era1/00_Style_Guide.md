# 🎨 CHRONOS VISUAL & PEDAGOGY GUIDE

## 1. The Aesthetic (Gen Alpha Sci-Fi)
*   **Vibe:** Valorant UI meets The Martian. High contrast, neon accents (Green/Blue/Pink) on dark backgrounds.
*   **Visual Prompts:** Every slide MUST include a bolded tag: `**[VISUAL: [Description] --style cinematic 3d render --ar 16:9]**`.
*   **Font Strategy:** Big, bold headers. Monospace font for ALL code snippets.

## 2. The Micro-Step Teaching Method
*   **Rule:** Never show a full block of code at once. Break it down.
*   **Execution:** Explain a single line of code (e.g., `print("Hello")`) across 3-4 slides:
    *   *Slide A:* `print` (The Verb)
    *   *Slide B:* `print(` (The Container)
    *   *Slide C:* `print("Hello"` (The Content)
    *   *Slide D:* `print("Hello")` (The Close)

## 3. The 17-Task Protocol
*   Every lesson MUST end with exactly:
    *   **5 Typing Tasks:** Exact syntax copying for muscle memory.
    *   **5 Debugging Tasks:** Broken code that the student must fix.
    *   **7 Writing Tasks:**
        *   *Recruit (2):* Easy 1-liners.
        *   *Agent (3):* Medium logic.
        *   *Architect (2):* Complex "Boss Level" word problems.
