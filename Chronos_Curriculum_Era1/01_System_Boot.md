# 🚀 Lesson 01: System Boot
**Topic:** `print()`, Strings, Syntax | **Era:** The Academy (Year 3042)

## 🎬 Phase 1: Mission Briefing (Slides 1-6)
1.  **Title Card:** "OPERATION CHRONOS: SYSTEM BOOT". `**[VISUAL: Cinematic title text glowing neon blue against a blurred futuristic server room, 8k render]**`

4.  **Objective:** Manually override the communication protocols to wake up "Py" (The AI).

6.  **Vocab:** **Syntax** (Grammar) and **String** (Text).

## 🧠 Phase 2: The Intel (Slides 7-14)
7.  **Analogy:** `print()` is the mouth of the computer. Without it, the computer thinks but cannot speak.
8.  **Diagram:** `**[VISUAL: Schematic of print("Hello"). Arrows pointing to 'print' (The Verb) and '("Hello")' (The Message)]**`
9.  **The Container:** Parentheses `()` are the airlock. Keep them closed or data leaks into space.
10. **The Wrapper:** Strings need quotes `""`. `**[VISUAL: Letters floating inside a glowing bubble (quotes). Letters outside are spilling on the floor.]**`
11. **Bad Code:** `print "Hello"` -> **CRASH**. `**[VISUAL: Red Alert siren]**`
12. **Bad Code:** `print(Hello)` -> **CRASH** (No quotes).
13. **Good Code:** `print("System Online")` -> **SUCCESS**.
14. **Quiz:** Which is valid? A) `print(Hi)` B) `print("Hi")`.

## 💻 Phase 3: The Uplink (Slides 15-22)
*Scenario: Sending the wake-up signal.*
15. **Setup:** Open the terminal.
16. **Micro-Step 1:** Type `print` (The Command).
17. **Micro-Step 2:** Type `(` (Open Channel).
18. **Micro-Step 3:** Type `"Wake up"` (The Signal).
19. **Micro-Step 4:** Type `)` (Seal Channel).
20. **Output:** `> Wake up`. `**[VISUAL: The Robot Py's eyes light up blue]**`
21. **Modify:** Add a second line: `print("Status Report")`.
22. **Interactive:** "Write a command to shout 'LAUNCH'!"

## ⚔️ Phase 4: The 17 Tasks (Slides 23-30)

### 🐞 5 Debugging Tasks (Glitch Repair)
1. `print("Hello World)` (Missing closing quote)
2. `print(Game Over)` (Missing both quotes)
3. `Print("Start")` (Capital P error)
4. `print "Loading"` (Missing parentheses)
5. `pint("Error")` (Spelling error)
