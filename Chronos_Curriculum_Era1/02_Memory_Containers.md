# 📦 Lesson 02: Memory Containers
**Topic:** Variables, Assignment `=`, Snake Case | **Era:** The Cargo Bay

## 🎬 Phase 1: Mission Briefing (Slides 1-6)
1.  **Title Card:** "MEMORY CONTAINERS". `**[VISUAL: A massive robotic arm lifting glowing neon cargo crates]**`
2.  **The Hook:** We need to pack the ship. We can't just throw items on the floor; we need labeled boxes.
3.  **Visual Metaphor:** Data without a container drifts away in zero-g.
4.  **The Solution:** Variables are the boxes.
5.  **Vocab:** **Variable** (Label), **Value** (Item), **Assignment** (Putting item in box).

## 🧠 Phase 2: The Intel (Slides 7-14)
7.  **The `=` Sign:** It is NOT "Equals". It is "Put Inside". Arrow: `Value` -> `Variable`.
8.  **Naming Rules:** **Snake Case**. `**[VISUAL: A robotic snake winding through the text 'my_variable_name']**`
9.  **Forbidden:** No spaces! No starting with numbers! `1st_player` = Crash.
10. **Dynamic Memory:** Replacing the value. `**[VISUAL: Taking a sword out of a box and putting a shield in.]**`
11. **Printing Variables:** `print(score)` (No quotes!).
12. **The Quote Trap:** `print("score")` prints the word "score", not the number inside.
13. **Quiz:** Which variable name is valid? `my gold` vs `my_gold`.

## 💻 Phase 3: The Uplink (Slides 15-22)
*Scenario: Loading Fuel.*
15. **Setup:** The fuel tank is empty.
16. **Micro-Step 1:** Create label `fuel`.
17. **Micro-Step 2:** Assign `=`.
18. **Micro-Step 3:** Value `100`. -> `fuel = 100`.
19. **Output:** `print(fuel)` shows `100`.
20. **Modify:** `fuel = 50`. Print again.
21. **Visual:** The fuel gauge drops.
22. **Interactive:** Create a variable for your own name.

### 🐞 5 Debugging Tasks
1. `my score = 10` (Remove space)
2. `1st_place = "John"` (Cannot start with number)
3. `print(Score)` (Case error: defined as 'score')
4. `gold = 100` then `print("gold")` (Remove quotes)
5. `high-score = 50` (Hyphens not allowed)
